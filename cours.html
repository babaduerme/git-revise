01 · CONFIGURER

Donner son identité à Git

Git associe chaque commit à un nom et une adresse. La configuration globale s’applique à tous vos dépôts.

git config
git config --global user.name "Votre Nom"
git config --global user.email "vous@exemple.fr"

À quoi ça sert : définir l’auteur des prochains commits. Piège : --global ne corrige pas une identité déjà enregistrée dans un dépôt local.

02 · DÉMARRER

Créer ou récupérer un dépôt

git init
mkdir mon-projet
cd mon-projet
git init

À quoi ça sert : créer un dépôt local dans le dossier courant.

git clone
git clone https://github.com/exemple/projet.git

À quoi ça sert : copier un dépôt existant et son historique. Piège : clonez une URL SSH/HTTPS correspondant à vos droits.

04 · BRANCHES

Isoler une idée

Une branche est un pointeur léger vers un commit. La pratique moderne privilégie switch pour changer de branche ; checkout reste compatible.

Créer, changer, fusionner
git switch -c feature/bonjour
git switch main
git merge feature/bonjour
git branch -d feature/bonjour

À quoi ça sert : travailler sans toucher à main avant validation. Piège : une fusion se fait depuis la branche qui reçoit les changements.

● A│├─● B (main)│ ╲└──● C (feature)

Fast-forward

Si main n’a pas avancé, son pointeur avance simplement vers C.

A—B—C ← main

Commit de merge

Si les deux branches ont divergé, Git crée M avec deux parents.

C—┐
A—B—M ← main
05 · SYNCHRONISER

Partager avec un remote

remote · push · fetch · pull
git remote add origin git@github.com:vous/projet.git
git push -u origin main
git fetch origin
git pull --rebase origin main

À quoi ça sert : déclarer, publier, récupérer puis intégrer les changements distants. Piège : fetch n’altère pas votre branche ; pull fait fetch puis intégration.

💻 Dépôt local
push →
← fetch
pull ↔
☁ Dépôt distant
06 · CORRIGER

Réparer sans paniquer

Amender
git commit --amend

Compléter le dernier commit non partagé. Ne réécrivez pas un commit déjà utilisé par d’autres.

Restaurer
git restore notes.md
git restore --staged notes.md

Annuler une modification ou retirer un fichier de l’index. Vérifiez avant d’écraser.

Remiser
git stash push -m "travail en cours"
git stash pop

Mettre temporairement de côté un travail non terminé. git stash list affiche les remises.

Retrouver
git reflog
git reset --hard HEAD@{2}

Le reflog garde les mouvements locaux de HEAD. Attention : --hard supprime les changements non commités.

07 · RÉÉCRIRE

Rebase : une histoire linéaire

Le rebase rejoue vos commits sur une nouvelle base. Il donne un historique propre, mais réécrit les identifiants : jamais sur une branche partagée sans accord.

Merge

A—B—M
╲ C—╱

Préserve les embranchements et crée parfois M.

Rebase

A—B—C'—D'

Rejoue C et D après B : fast-forward possible.

Rebase interactif
git rebase -i HEAD~3
pick 1a1 premier essai
squash 2b2 correction
fixup 3c3 détail
reword 4d4 documentation

À quoi ça sert : nettoyer les derniers commits. Piège : drop supprime un commit ; résolvez chaque conflit puis git rebase --continue.

avant : A—B—C—Drebase -i / squashaprès : A—D'
08 · CONFLITS

Lire et résoudre

Un conflit signifie que Git ne peut pas choisir entre deux modifications. Il ne s’agit pas d’une erreur irrécupérable.

<<<<<<< HEAD
Bonjour depuis main
=======
Bonjour depuis feature
>>>>>>> feature
1 · choisir ou combiner le contenu2 · supprimer les marqueurs3 · git add fichier4 · git commit ou git rebase --continue
Réflexe utile

Après résolution, lancez les tests, git diff --check, puis seulement la commande de finalisation.

POUR ALLER PLUS LOIN

Les pratiques autour de Git

Hooks

Un hook pre-commit lance des contrôles avant l’enregistrement.

SSH & signatures

ssh-keygen -t ed25519 crée une paire ; protégez la privée en 600, le dossier .ssh en 700 et la publique en 644. Une signature GPG/SSH atteste l’auteur.

Ignore & outils

.gitignore exclut les secrets et artefacts. GitKraken et VS Code offrent une interface, mais montrent toujours le même modèle.

GitHub, GitLab & workflows

GitHub met l’accent sur la communauté et Actions ; GitLab propose une CI intégrée et un mode self-hosted.
