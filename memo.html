À GARDER SOUS LA MAIN

La fiche mémo
qui tient sur une page.

Commencer

git config --global user.name "Nom"
git config --global user.email "mail"
git init
git clone URL

Cycle quotidien

git status
git add fichier
git diff
git diff --staged
git commit -m "Décrit le changement"
git log --all --oneline --graph --stat

Branches

git branch
git switch -c feature/nom
git switch main
git merge feature/nom
git branch -d feature/nom

Remote

git remote -v
git remote add origin URL
git push -u origin main
git fetch origin
git pull --rebase

Se rattraper

git commit --amend
git restore fichier
git restore --staged fichier
git stash push -m "en cours"
git stash list
git stash pop
git reflog

Historique

git rebase main
git rebase -i HEAD~3
git rebase --continue
git rebase --abort

Avant reset --hard ou un rebase : vérifiez git status, préservez ce qui compte et ne réécrivez pas une branche partagée.
